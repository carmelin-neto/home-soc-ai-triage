# home-soc-ai-triage
A self-hosted Wazuh SIEM ingesting real Suricata detection data, with a locally-run LLM triage layer on top — built after solving a genuine Wazuh ingestion gotcha and pivoting from a paid API to a local model. The AI's output is validated critically, not celebrated blindly: it got the port wrong and missed a key detail, and the write-up says so.
